# Информационные инструменты Jarvis, 2 ноября 2026

GPT-6 Luna через AI/ML API, существующий HTTPS API и Piper/XTTS сохранены. Новое APK для этой доработки не требуется.

Добавлены `get_weather`, `search_web`, `fetch_page`, `calculate`, `convert_units`. Инструменты описаны в `information_tools.py`, вызовами управляет `provider.py`.

## Поведение

- На запрос погоды выполняется отдельный запрос Open-Meteo. Если в текущей фразе город не указан, ассистент должен уточнить его, даже если город упоминался раньше. Прогноз использует локальные даты и часовой пояс места, ветер в м/с. При неоднозначном или неизвестном городе запрашивается уточнение.
- Поиск по умолчанию использует DDGS. При наличии отдельной переменной `SERPAPI_API_KEY` первым пробуется Google через SerpApi, затем DDGS как резерв. Отсутствие ключа SerpApi не отключает поиск. Подключение ключа требует перезапуска сервера. Ключ AI/ML API нельзя использовать вместо поискового ключа.
- Модель может выполнить несколько раундов инструментов: поиск, чтение страницы, дополнительный запрос, ответ. Ограничения: до восьми информационных вызовов и пяти обращений к модели, мягкий бюджет инструментального цикла 70 секунд. Сетевые ошибки возвращаются как ошибки, а не как отсутствие фактов.
- Чтение страниц поддерживает публичный HTML/текст/JSON, не запускает JavaScript, не входит в аккаунты и не обходит блокировки/платный доступ. Ограничивает объём и перенаправления; приватные/служебные адреса, нестандартные порты и URL с учётными данными запрещены. DNS-адрес проверяется и фиксируется на соединение, TLS-проверка сохраняется.
- Калькулятор поддерживает числа, скобки и операции `+ - * / **`, ограничивает сложность и степень, не исполняет Python-код. Проценты переводятся в выражение, например `2400*15/100`. Decimal использует точность 28 значащих цифр; бесконечные десятичные дроби округляются.
- Единицы: длина, масса, время, объём, скорость, площадь, температура. Валюты не считаются единицами с постоянным коэффициентом. Несовместимые единицы и температура ниже абсолютного нуля отклоняются.

Примеры: «Какая погода завтра в Будапеште?», «Какая погода завтра?» (уточнение города), «Сколько будет 15% от 2400?», «Сколько километров в пяти милях?», «Найди в интернете …», «Прочитай страницу https://…».

## Проверка

Из каталога server в окружении с зависимостями сервера:

```text
python -m unittest discover -s . -v
```

Новые проверки охватывают вычисления, ошибки, преобразования, город/дату прогноза, запрет приватных URL и опасных перенаправлений, многошаговые вызовы, передачу ошибки модели и сохранение прежних функций провайдера.

На рабочем сервере новые файлы сначала проверялись в `C:\Jarvis\updates\information-20261102`. Перед заменой сделана резервная копия `C:\Jarvis\backups\information-20261102\provider.py`. Внешние API и точность обработки реального микрофонного звука требуют эксплуатационной проверки; успешная проверка синтетического аудио не заменяет испытание на телефоне в шуме.

## Откат

Остановить задачу `JarvisAssistant`, восстановить `provider.py` из указанной резервной копии в `C:\Jarvis\provider.py`, снова запустить задачу. Новый `information_tools.py` старой версией не используется. Токены, сертификаты, модели и архивы менять не нужно.

Новые заметки, таймеры, фоновые сводки, дополнительные Android-действия и умный дом относятся к следующим этапам и этой доработкой не добавлены.
