# Jarvis 2.7 — персонализация, знания, исследования и фоновый сбор

Основная модель остаётся GPT-6 Luna через AI/ML API, голос — существующий XTTS. Новые функции используют CPU, SQLite и внешние информационные источники; отдельная локальная LLM не добавлена.

## Покрытие второй группы ТЗ

| Пункт | Реализация |
|---|---|
| Стиль общения | Сдержанный характер Jarvis по умолчанию, серьёзный тон для технических/важных вопросов; голосом сохраняются настройки стиля, юмора и длины ответа. |
| Базовая персонализация | Постоянные явные предпочтения: имя/обращение, рабочие часы, любимые инструменты, стиль, юмор, длина, язык. Факты не извлекаются тайно из чужих документов. |
| Индивидуальные команды | Постоянные сокращения с точным совпадением всей фразы. Раскрываются в заданную владельцем команду; не являются нечётким семантическим распознаванием. |
| Текущее состояние | «Занят», «отвечай по существу» и другие явно заданные состояния с временем действия 1..1440 минут. Усталость не диагностируется по голосу. |
| Дополнительные языки | Подключены 17 языков установленного XTTS и выбор языка по Whisper: ru,en,es,fr,de,it,pt,pl,tr,nl,cs,ar,zh-cn,hu,ko,ja,hi. Текстовое определение языка эвристическое; короткие фразы могут быть неоднозначны. Интерфейс телефона/часть сообщений исполнителей остаются RU/EN. |
| Сводки и отчёты | Голосовое резюме полученных данных, постоянные отчёты и анализы в рабочем пространстве. |
| Новости и мониторинг | Google News RSS с датами, источниками и удалением точных повторов; мониторинг изменений явно заданной публичной страницы. RSS — агрегатор, не независимая проверка фактов. |
| Фоновый сбор | Отдельный поток коллектора, задания и результаты в SQLite; после перезапуска расписания сохраняются. Начальные темы обновляются раз в час без уведомлений. |
| Проактивные уведомления | На изменение страницы, запланированную новостную/погодную сводку, явно запрошенное завершение записи отчёта. Постоянная серверная очередь, подтверждение доставки телефоном. |
| Поиск по внутренним данным | Поиск слов в импортированных документах, заметках/задачах/покупках и сохранённых исследовательских записях. Не семантический поиск. |
| Простой импорт | TXT/MD/JSON/CSV, текстовые PDF, DOCX, XLSX до 4 МиБ. Выбор файла или «Поделиться» на Android с подтверждением передачи на собственный сервер. |
| Открытые сведения | Поиск людей, организаций, отчётности и научных публикаций через существующий web-поиск и сбор публичных страниц. Нет доступа к закрытым базам. |
| Небольшие материалы | Сопоставление текстов, противоречий и хронологии через модель на основании реально прочитанных фрагментов/источников. Большой документ читается порциями. |
| Метаданные файлов | Размер, SHA256, доступные свойства PDF/DOCX/XLSX, EXIF/GPS/размеры изображений JPEG/PNG/WebP. Изображения импортируются только как метаданные, без OCR и визуального распознавания. Метаданные могут быть подделаны. |
| Исследовательские заготовки | Сохраняемые концепции, спецификации, гипотезы, планы экспериментов; требования/допущения/неизвестные параметры/проверки включаются в структуру. |
| Лабораторный журнал | Постоянные записи с проектом, заголовком, текстом и ссылками на реальные ID импортированных источников. Измерения не придумываются. |
| Простые расчёты | Закон Ома, электрическая мощность/энергия, последовательные/параллельные резисторы, Q=m*c*ΔT, объём параллелепипеда/цилиндра/сферы, среднее/медиана/разброс/стандартная ошибка. Входы в СИ, ограниченные конечные числа. Это идеализированные формулы, не CAD/FEA и не сертификация конструкции. |

## Примеры голосовых команд

- «Запомни: всегда отвечай кратко» / «Добавь немного иронии в обычные разговоры».
- «Запомни сокращение: „мой робот“ означает „найди документы про пылесос“».
- «Я занят, следующие полчаса отвечай только по существу».
- «Импортируй документ» — затем выбрать файл и подтвердить импорт.
- «Найди в моей библиотеке документы про фильтры» / «Прочитай этот документ».
- «Какие метаданные есть у импортированной фотографии?».
- «Какие темы новостей я отслеживаю?» / «Добавь тему „космонавтика“».
- «Сделай сводку новостей по моим темам» — ответ озвучивается обычным голосовым трактом.
- «Присылай новостную сводку каждый день в 08:00» — используется часовой пояс телефона, если он передан.
- «Собирай погоду для Москвы без уведомлений» / «Каждый день в 08:30 сообщай погоду в Будапеште».
- «Следи за изменениями страницы https://… и уведомляй».
- «Покажи фоновые задания» / «Приостанови это задание» / «Возобнови» / «Удали».
- «Собери источники по материалам корпуса робота и сравни их».
- «Подготовь и сохрани предварительную концепцию датчика освещённости: требования, неизвестные параметры и проверка».
- «Сохрани в лабораторный журнал проекта „робот“: измерено 12 В и 100 Ом».
- «Рассчитай ток при 12 В и 100 Ом» / «Посчитай статистику измерений 1,2,3,4,5».

Начальные темы владельца: Формула-1, политика, экономика. Дополнительные темы создаются голосом. Время регулярных уведомлений не выбрано, поэтому они первоначально выключены. Города погоды не подставляются автоматически.

## Хранение и доставка

Профиль, библиотека, исследовательские записи, темы, задания, кэш и очередь уведомлений — `C:\Jarvis\workspace.sqlite3`. Старые заметки/покупки остаются в organizer.sqlite3. Источник импортированного файла временно помещается в частную папку library, затем удаляется после извлечения текста; сохраняются извлечённый текст и метаданные. Разрешён ручной импорт имени файла только внутри этой папки, не произвольного пути сервера.

Фоновый поток выполняется вместе с JarvisAssistant; отдельное окно/приложение не требуется. Сетевые/инструментальные ошибки видны в статусе задания. Кэш содержит время получения; устаревшие сведения должны явно обозначаться. При мониторинге первая загрузка задаёт базовую версию и не вызывает уведомление. Сравниваются первые 12000 символов извлечённого текста, поэтому динамические элементы страницы могут создавать лишние события, а изменения за пределом фрагмента не обнаруживаются.

Телефон получает уведомления примерно раз в 30 секунд при работающей службе ассистента. Дополнительно установлен постоянный JobScheduler на 15 минут; ОС и сеть могут задерживать запуск. Это не канал гарантированного экстренного оповещения. При выключенных уведомлениях события не помечаются доставленными. Повторная доставка использует тот же ID; подтверждение отправляется после показа. Регулярная сводка приходит текстовым уведомлением, её можно попросить прочитать голосом; самопроизвольное громкое воспроизведение не включено.

PDF без текстового слоя требует OCR и будет отклонён. Формулы XLSX читаются как формулы, а не вычисляются. Большие/сложные файлы ограничены по размеру, числу страниц/строк и времени разбора. Черновики концепций и отчётов не доказывают, что эксперимент проведён или конструкция проверена.

## Развёртывание

Новые серверные модули: workspace_store.py, knowledge_tools.py, library_extract.py, background_services.py, workspace_api.py. Изменены provider.py, server.py, information_tools.py, reply_language.py, voice_worker.py. Добавлены pypdf, python-docx, openpyxl, Pillow в среду основного сервера. Среда XTTS не переустанавливалась, использованы её существующие модели/языки.

Новые Android-компоненты: DocumentImport, InboxSync; версия 2.7 / versionCode 18. Управление центральным кругом сохранено. Персональные параметры URL/TLS в приватном Net.java сохранены; изменён только таймаут запросов очереди.

Резервная копия сервера: `C:\Jarvis\backups\workspace-20261102`; предыдущего APK/частных файлов: Private-Project/versions/before-2.7-workspace. При откате кода сохранять workspace.sqlite3 и organizer.sqlite3.

## Проверки

Автоматические тесты покрывают профиль/сокращения/временное состояние, постоянное хранение, поиск/метаданные, журнал/источники, очередь и подтверждение, темы, кэш при сетевой ошибке, базовую версию/изменение страницы, расписания, запрет приватных URL и произвольных путей, реальный импорт DOCX/XLSX/TXT, отказ PDF без текста, метаданные изображения, формулы и языки.

На настоящем AI/ML API проверены предпочтение краткости, сокращение и его выполнение, временная занятость, поиск файла, темы/добавление темы/новостная сводка, инженерный расчёт/статистика, сохранение журнала/концепции, действие импорта и французский ответ. Проверена рабочая цепочка французское аудио XTTS → Whisper → модель → французская озвучка. Все 17 языков в реальной речи по отдельности не проверялись.

В рабочем развёртывании все три начальные темы собраны с last_status=ok, уведомления выключены. Через установленный Jarvis 2.7 на Xiaomi показано настоящее серверное уведомление и получен ACK; проверочная запись удалена из серверной очереди. На рабочем API выполнен импорт текстового документа, поиск проверочного кода и озвученный ответ; тестовый документ удалён. Play Protect отклонил отдельный временный инструментальный APK, поэтому автоматическая проверка системного выбора файла/меню «Поделиться» на устройстве не завершена. Сам рабочий APK 2.7 установлен успешно.
