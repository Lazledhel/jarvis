# Управление телефоном — Jarvis Android 2.6

Расширен инструмент control_phone; GPT-6 Luna через AI/ML API сохраняется. Сервер готовит проверенное действие, Android исполняет его и отправляет результат в журнал. Голосовое подтверждение до исполнения означает передачу команды, а не гарантированный успех.

Команды:

| Пример | Реализация |
|---|---|
| «Открой YouTube / Telegram / Chrome / [название]» | Поиск приложения и запуск на телефоне; адресная книга/список приложений не загружаются на сервер. При неоднозначности предлагается выбор. |
| «Открой сайт https://example.org» | Chrome, если доступен, иначе браузер Android. Только HTTP/HTTPS; URL с учётными данными и служебные схемы запрещены. |
| «Включи / выключи фонарик» | CameraManager, задняя вспышка. Требуется разрешение камеры. Проверяется обратное уведомление состояния. |
| «Громкость 35 процентов / тише / громче» | По умолчанию мультимедиа, также поддержаны звонок и будильник. Изменение проверяется чтением текущего уровня. |
| «Яркость 45 процентов / сделай экран ярче» | Глобальная ручная яркость. При первом использовании открывается системный доступ к изменению настроек; после выдачи выполняется команда. Минимум ограничен значением 1 из 255. |
| «Включи / выключи „Не беспокоить“» | После выдачи доступа к политике уведомлений — режим приоритетных уведомлений / обычный режим. Проверяется фактический interruption filter. |
| «Включи / выключи Wi-Fi» | Открывается системная панель Wi-Fi; состояние выбирается пользователем. Голос не сообщает о якобы состоявшемся переключении. |
| «Включи Bluetooth» | Системный запрос включения, при необходимости разрешение Bluetooth Connect. |
| «Выключи Bluetooth» | Открываются системные настройки Bluetooth. |
| «Открой камеру / сделай селфи» | Открывается приложение камеры с подсказкой заднего/фронтального объектива. Конкретная камера может игнорировать подсказку. Съёмка автоматически не выполняется. |
| «Поставь музыку на паузу / продолжи / следующий трек» | Стандартная media key активному плееру. Доставка команды не доказывает начало/остановку воспроизведения. |

Для действий, которым нужен экран, используется существующая ActionScreen и уведомление. Если Android блокирует запуск Activity из фона или экран заблокирован, нужно открыть уведомление/разблокировать телефон. Новых постоянных кнопок на главном экране не добавлено: интерфейс 2.5 с центральным кругом сохранён.

Разрешения камеры, изменения настроек, DND и Bluetooth выдаются при использовании соответствующей функции. Доступ к чужим уведомлениям, Accessibility, root и автоматическая съёмка не добавлялись. Также не добавлены отправка сообщений, чтение экрана или скриншоты.

## Изменения

- Сервер: phone_commands.py (схема и валидация), provider.py (выбор инструментов).
- Android: DeviceControls.java, Actions.java, ActionScreen.java, дополнительные permissions/queries в manifest, версия 2.6 / versionCode 17.
- Приватный Net.java и настройки TLS/сервера сохранены.
- Резервная копия серверных файлов: C:\Jarvis\backups\device-20261102; предыдущий APK/исходники: Private-Project/versions/before-2.6-device.

48 автоматических серверных тестов прошли локально, 14 профильных — на сервере. В изолированном каталоге проверены 10 настоящих запросов к GPT-6 Luna: модель выбрала нужный тип действия для всех перечисленных команд. Часть функций Android требует проверки после разрешения системного доступа пользователем; при отсутствии доступа команда не должна считаться выполненной.

Дополнительно на Xiaomi 12X проверены фактические изменения громкости, яркости и состояния фонарика, а также настоящая цепочка телефон → HTTPS API → модель → Actions → изменение громкости. Проверена доступность обработчиков YouTube, камеры, Wi-Fi и Bluetooth; это не проверка всех экранов и переключений. Для теста временно выдавались разрешение камеры и WRITE_SETTINGS, после испытания возвращены исходные значения разрешений, громкость, режим/уровень яркости и состояние фонарика. DND access на телефоне не выдан, его фактическое переключение не проверялось. Тестовый APK удалён после проверки.
